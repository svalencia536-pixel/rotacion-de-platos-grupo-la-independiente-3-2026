# Dashboard de Ventas · Grupo La Independiente

Aplicación web estática (HTML/CSS/JS, sin backend) con el dashboard de ventas de Grupo La Independiente (enero–junio 2026).

## Desarrollo local

Simplemente abre `index.html` en el navegador.

## Despliegue

Sitio estático (`index.html` en la raíz). Se despliega en [Railway](https://railway.app) conectando este repositorio de GitHub.
